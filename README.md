# 라벨 검수 뷰어

라벨링 업체가 납품한 COCO 세그멘테이션 데이터(Roboflow export: `_annotations.coco.json` + `raw/*.png`)를
브라우저에서 한 장씩 보면서 OK / NG / 보류를 판정하는 도구입니다.

- Python 3.8+ 표준 라이브러리만으로 동작합니다. 따로 설치할 패키지는 없습니다.
- `opencv-python`과 `numpy`가 있으면 '중복/겹침' 자동검사를 폴리곤 단위로 더 정확하게 합니다. 없으면 bbox 기준으로 검사합니다.

## 실행

```bash
git clone <이 저장소 주소> label_viewer
cd label_viewer
python3 viewer.py
```

브라우저가 자동으로 열립니다. 안 열리면 http://127.0.0.1:8765/ 로 접속하세요. 끌 때는 터미널에서 `Ctrl+C`를 누릅니다.

### 데이터셋 열기
화면 위쪽 칸에 **데이터셋 폴더 경로**를 넣고 Enter(또는 **열기**)를 누르면 됩니다.

```
/home/roboe/superbai/data/superbai_batch02_2993ea_261028
```

- zip을 푼 바깥 폴더를 넣어도 됩니다. `_annotations.coco.json`이 있는 폴더를 두 단계 아래까지 자동으로 찾습니다(`__MACOSX`는 무시).
- 마지막으로 연 경로는 브라우저가 기억해서, 다음에 열면 칸에 미리 채워져 있습니다.
- 실행할 때 경로를 바로 줘도 됩니다.

  ```bash
  python3 viewer.py /home/roboe/superbai/data/superbai_batch02_2993ea_261028
  ```

### 옵션

| 옵션 | 설명 |
|---|---|
| `--port 8766` | 포트 변경 (기본 8765) |
| `--host 0.0.0.0` | 다른 PC에서 `http://<이 PC IP>:8765/` 로 접속 허용 |
| `--no-browser` | 브라우저 자동 실행 안 함 |
| `--tiny 300` | 이 면적(px²) 미만 라벨을 '작은 영역'으로 표시 |
| `--overlap 0.8` | 두 라벨이 작은 쪽 면적의 이 비율 이상 겹치면 '중복/겹침'으로 표시 |

`Address already in use` 오류가 나면 이미 같은 포트로 뷰어가 떠 있는 것입니다. 그 창을 끄거나 `fuser -k 8765/tcp`로 내린 뒤 다시 실행하세요.

## 검수 방법

| 키 | 동작 |
|---|---|
| `←` `→` / `A` `D` | 이전 / 다음 이미지 |
| `N` | 다음 미검수 이미지 |
| `1` `2` `3` `0` | OK / NG / 보류 / 판정 해제 (OK는 자동으로 다음 이미지) |

1. 이미지를 보고 `1`(OK) / `2`(NG) / `3`(보류)을 누릅니다.
2. `2`(NG)를 누르면 커서가 **메모** 칸으로 이동합니다. 무엇이 문제인지 적고 `Enter`를 누르면 다음 이미지로 넘어갑니다(줄바꿈은 `Shift+Enter`).
3. 판정과 메모는 누르는 즉시 **자동 저장**됩니다. 저장 버튼은 없습니다. 껐다 켜도 이어서 할 수 있습니다.
4. 다 끝나면 오른쪽 위 **완료** 버튼을 누릅니다.

보조 기능: `Space`를 누르는 동안 라벨 숨김, `T` 채우기 깜빡임, 휠 확대 / 드래그 이동 / `R` 화면 맞춤, 왼쪽 위 파일명 검색·상태 필터.

## 완료하면 생기는 파일
**완료**를 누르면 데이터셋 폴더 옆에 결과 zip이 만들어지고, 브라우저로도 같은 파일이 다운로드됩니다. 이 zip을 구글 드라이브에 올리면 됩니다.

```
<데이터셋 폴더 이름>_review_<날짜_시각>.zip
└── <데이터셋 폴더 이름>_review/
    ├── _annotations.coco.json   원본 라벨 (그대로)
    ├── review_results.json      판정·메모 전체
    ├── review.csv               판정·메모 표 (엑셀 호환)
    ├── ok_files.txt / ng_files.txt / hold_files.txt
    └── summary.txt              OK / NG / 보류 / 미검수 개수
```

- 이미지는 넣지 않습니다(이미 드라이브에 있으므로). 그래서 zip은 수 MB 수준입니다.
- 미검수나 메모 없는 NG가 남아 있으면 완료 전에 경고가 뜹니다. 다시 눌러 새 zip을 만들 수 있습니다(파일명에 시각이 붙어 덮어쓰지 않음).

## 주의
- 판정은 데이터셋 폴더 안의 `review_results.json`에 저장됩니다. 원본 `_annotations.coco.json`과 이미지는 건드리지 않습니다.
- 서버(터미널)가 꺼진 상태에서 판정하면 화면 위에 빨간 배너가 뜹니다. 탭을 닫지 말고 서버를 다시 실행하면 자동으로 저장됩니다.
- 같은 데이터셋 폴더를 여는 뷰어를 동시에 두 개 띄우지 마세요. 서로의 기록을 덮어씁니다.

## 보조 스크립트

### 검수자별로 나누기 — `split_parts.py`

```bash
python3 split_parts.py <데이터셋 폴더> --size 1000    # 1000장씩
python3 split_parts.py <데이터셋 폴더> --parts 3      # 3등분
```

`<데이터셋 폴더>_parts/<이름>_part1_1000ea/` 형태로 나뉩니다. 각 폴더는 원본과 같은 구조라 그대로 뷰어로 열 수 있습니다.
같은 장면이 한 사람에게 가도록 원본 순서대로 앞에서부터 자릅니다.

### OK / NG 분리 — `export_split.py`

```bash
python3 export_split.py <검수한 데이터셋 폴더>               # -> <폴더>_reviewed/{ok,ng}
python3 export_split.py <검수한 데이터셋 폴더> --overwrite   # 판정을 바꾼 뒤 다시 만들 때
```

두 스크립트 모두 이미지는 **하드링크**로 넣어 디스크를 추가로 쓰지 않습니다. 다른 디스크로 내보내거나 완전히 별개인 복사본이 필요하면 `--copy`를 붙이세요.
압축하거나 구글 드라이브에 올릴 때는 일반 파일과 똑같이 동작합니다.
