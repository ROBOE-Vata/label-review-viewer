# 라벨 검수 뷰어

라벨링 업체가 납품한 COCO 세그멘테이션 데이터(Roboflow export: `_annotations.coco.json` + `raw/*.png`)를
브라우저에서 한 장씩 보면서 OK / NG / 보류를 판정하는 도구입니다.

- Python 3.8+ 표준 라이브러리만으로 동작합니다. 따로 설치할 패키지는 없습니다.
- `opencv-python`과 `numpy`가 있으면 '중복/겹침' 자동검사를 폴리곤 단위로 더 정확하게 합니다. 없으면 bbox 기준으로 검사합니다.

## 실행

```bash
cd label_viewer
python3 viewer.py
```

브라우저가 자동으로 열립니다. 안 열리면 http://127.0.0.1:8765/ 로 접속하세요. 끌 때는 터미널에서 `Ctrl+C`를 누릅니다.

### 데이터셋 열기
화면 위쪽 칸에 **데이터셋 폴더 경로**에 데이터셋 경로를 넣고 Enter(또는 **열기**)를 누르면 됩니다.

```
/home/roboe/superbai/data/superbai_batch02_2993ea_261028/superbai_batch02_2993ea_261028_parts/superbai_batch02_2993ea_261028_part1_vata
```


## 사용법

| 키 | 동작 |
|---|---|
| `←` `→` / `A` `D` | 이전 / 다음 이미지 |
| `N` | 다음 미검수 이미지 |
| `1` `2` `3` `0` | OK / NG / 보류 / 판정 해제 (OK는 자동으로 다음 이미지) |


- 왼쪽 위 **파일명 검색**에 프레임 번호 일부(예: `025735`)만 넣어도 찾을 수 있습니다.
- 상태(미검수/OK/NG/보류), 클러스터, 자동검사 항목으로 목록을 거를 수 있습니다.
- NG 사유 버튼과 메모를 남겨 두면 업체에 근거로 그대로 전달할 수 있습니다.
